# **App Name**: KanbanZen

## Core Features:

- Kanban Board View: Display a dynamic Kanban board with draggable cards and columns fetched from the API.
- Swimlanes and Zones: Implement horizontal swimlanes within the Kanban board, along with collapsible zones on either side for staging cards.
- Card Detail Panel: Create a slide-out side panel for detailed card views, including inline editing, rich text descriptions, checklists, comments, and activity logs.
- Card Creation: Implement a modal form for creating new cards, with support for pre-filling fields from saved templates.
- Backlog View: Develop a separate route for a table/list view of all cards, with sorting, search, and filtering capabilities.
- Board Settings: Provide a settings panel for managing columns, lanes, custom fields, card templates, and board members.
- Export Functionality: Implement toolbar buttons to export the board as CSV or JSON files, triggering a download.
- Close with Evidence AI tool: Add an LLM tool to assess the relevance of evidence text entered when moving a card to Done status.

## Style Guidelines:

- Primary color: Dark Indigo (#4F46E5) for a professional and focused feel.
- Background color: Very dark gray (#1A1A1A) for a dark-first theme.
- Accent color: Purple (#9333EA) to highlight interactive elements and priorities.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined, objective look. 
- Monospace accents for IDs/metadata: 'Source Code Pro' (monospace).
- Simple, consistent icons for actions and status indicators, prioritizing clarity and ease of use.
- Clean and minimal design inspired by Linear and Trello, with dense information display and subtle borders.
- Smooth transitions for drag and drop, panel open/close, and other interactive elements, enhancing user experience.
